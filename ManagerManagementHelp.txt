MANAGER MANAGEMENT HELP

The Manager Management screen allows managers to view and maintain manager accounts.

SEARCH
Enter a manager's name, username, email, or other supported search information in the Search box and click Search.

CLEAR
Click Clear to remove the current search and display all manager accounts.

ADD MANAGER
Click Add Manager to create a new manager account.
Required information must be entered before the account can be created.

EDIT MANAGER
Select a manager from the list and click Edit Manager to update that manager's information.

DISABLE / ENABLE
Select a manager and click Disable / Enable to change the manager's account status.

A disabled manager cannot use the account to log in.

You cannot disable your own manager account while you are currently logged in.

CLOSE
Click Close to return to the Manager screen.
