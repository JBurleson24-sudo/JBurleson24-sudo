DISCOUNT EDITOR HELP

The Discount Editor is used to create or update discount and promotional codes.

DISCOUNT CODE
Enter the code that customers or managers will use to apply the promotion.

DESCRIPTION
Enter a short description explaining the discount.

APPLIES TO
Entire Order:
The discount applies to the entire cart subtotal.

Individual Item:
The discount applies only to the selected product.

PRODUCT
This field is required when Individual Item is selected.
Choose the inventory item that the discount applies to.

DISCOUNT TYPE
Percentage:
Removes a percentage from the applicable item or order.

Dollar Amount:
Removes a fixed dollar amount from the applicable item or order.

DISCOUNT AMOUNT
Enter the discount value.

Examples:
10.00 with Percentage means 10 percent off.
5.00 with Dollar Amount means $5.00 off.

START DATE
The promotion cannot be used before this date.

EXPIRATION DATE
The promotion cannot be used after this date.
The expiration date cannot occur before the start date.

SAVE / SAVE CHANGES
Click Save to create a new discount.

When editing an existing discount, click Save Changes to update it.

CANCEL
Click Cancel to close the Discount Editor without saving changes.

HELP
Click Help to display this help information.
